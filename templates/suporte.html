Perguntas Frequentes (FAQ)

Não consigo visualizar o arquivo da publicação. O que fazer?
Verifique se o arquivo foi anexado corretamente. Em alguns formatos, o sistema converte para PDF para preview. Se persistir, use o botão de download para baixar e abrir localmente.
Como faço o download de uma publicação?
No modal da publicação, clique em “Fazer download”. Uma barra de progresso aparece e o arquivo é salvo com o nome sugerido.
Posso filtrar ou buscar publicações específicas?
Sim. Utilize a busca por texto (título/tipo/curso) e os filtros de status para encontrar rapidamente o que precisa.
Como altero minha foto ou dados do perfil?
Abra o menu do usuário no topo (avatar) e utilize as opções disponíveis. Dependendo do seu perfil, algumas alterações podem exigir contato com o administrador.
Recebi um erro ou comportamento inesperado. Como reporto?
Use o formulário abaixo para enviar sua mensagem ao suporte. Descreva o passo a passo, inclua o ID da publicação (se houver) e, opcionalmente, anexe uma imagem do erro.
